# Requirements

## v1 Requirements

### Inventory
- [ ] INV-01: User can view a list of books (title, author, ISBN, available copies)
- [ ] INV-02: User can add a new book with title, author, ISBN, and copy count
- [ ] INV-03: User can edit an existing book's details
- [ ] INV-04: User can delete a book from inventory

### Rental
- [ ] RENT-01: User can add selected books to a rental cart
- [ ] RENT-02: User can submit a rental request form with validated name, email, phone, and pickup date
- [ ] RENT-03: User receives a confirmation popup with a reservation ID and instructions to go to the front desk

### UI/UX
- [ ] UI-01: Responsive, showcase-friendly layout with navigation between Inventory and Rent pages

## v2 Requirements

- RENT-04: Persist rentals to local storage
- INV-05: Search/filter books by title/author

## Out of Scope

- User accounts / authentication — no users needed for showcase
- Payments — not part of showcase scope
- Real backend or database — in-memory mock state
- Multi-branch library support — single branch scope
